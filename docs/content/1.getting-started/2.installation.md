## Requirements

| | |
|---|---|
| PHP | 8.2 or newer |
| Laravel | 12.x or 13.x |

## Install

```bash
composer require youbar/easy-crud
```

The service provider is auto-discovered. There is nothing to register.

## Publish the config

Worth doing straight away: the conventions table ships empty, so this is where
you tell easy-crud where your classes live.

```bash
php artisan vendor:publish --tag=easy-crud-config
```

That writes `config/easy-crud.php`. Every key is documented inline, and the [configuration reference](/reference/configuration) reproduces it in full. Start with [the conventions table](/core-concepts/conventions).

## Check what it found

At any point, ask the package what it resolved for a model:

```bash
php artisan easy-crud:conventions Post
```

This is the fastest answer to *"why isn't my validation running"* and most other questions you will have.
