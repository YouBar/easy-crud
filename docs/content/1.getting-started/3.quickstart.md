description: A working CRUD API in five minutes.

## 1. A controller

The model is the only required declaration.

```php [app/Http/Controllers/PostController.php]
namespace App\Http\Controllers;

use App\Models\Post;
use Youbar\EasyCrud\CrudController;

class PostController extends CrudController
{
    protected string $model = Post::class;
}
```

## 2. A route

```php [routes/api.php]
use Youbar\EasyCrud\CrudController;

Route::crud('posts', PostController::class);
```

That registers five routes:

| Method | URI | Action |
|---|---|---|
| `GET` | `/posts` | index |
| `POST` | `/posts` | store |
| `GET` | `/posts/{post}` | show |
| `PUT` `PATCH` | `/posts/{post}` | update |
| `DELETE` | `/posts/{post}` | destroy |

## 3. Point it at your classes

Out of the box nothing is resolved: you get plain JSON and no validation. One
config entry fixes both, for every model in the application.

```php [config/easy-crud.php]
'conventions' => [
    'resource' => ['App\Http\Resources\{Model}Resource'],
    'request'  => ['App\Http\Requests\{Action}{Model}Request'],
],
```

Now `PostResource` and `StorePostRequest` are used if they exist, and skipped if
they don't — no controller change either way.

## 4. That's it

```bash
curl localhost/api/posts
curl localhost/api/posts?perPage=50
curl -X POST localhost/api/posts -d '{"title":"Hello"}'
```

::warning
With no request class and no `rules()`, **nothing is validated** — the input goes straight to the model, and your `$fillable` / `$guarded` is the only filter. That is what makes this page short. Read [fallbacks](/core-concepts/fallbacks) before shipping it.
::

## 5. Grow into it

Every file below is optional, and each one is picked up the moment it exists.

::steps{level="3"}
### Add a resource

With the `resource` row above, creating `App\Http\Resources\PostResource` is enough.

### Add validation

Create `App\Http\Requests\StorePostRequest`, or skip request classes entirely:

```php
protected function rules(string $action): array
{
    return $action === 'store' ? ['title' => 'required|string'] : [];
}
```

### Add a policy

Create `App\Policies\PostPolicy`. Abilities it defines are enforced; abilities it omits are skipped.

### Add business logic

Override a method — [there are about a dozen](/customisation/overriding-methods):

```php
protected function create(array $data): Model
{
    return app(PostService::class)->create($data);
}
```
::
