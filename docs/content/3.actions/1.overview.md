---
title: The five actions
description: What each action does, and which methods it calls.
---

Every action runs the same pipeline:

```
resolve → authorize → validate → act → prepare → transform → respond
```

## index

```
authorizeAction(viewAny) → validated(index) → scope() → filter()
  → with('index') → paginate() → prepare() → transform()
```

Returns a paginated resource collection. `scope()` narrows to what the user may see; `filter()` applies what they asked for.

## show

```
find($key) → authorizeAction(view) → validated(show)
  → with('show') → prepare() → transform()
```

404s via `ModelNotFoundException` when `resolveRouteBinding` returns nothing.

## store

```
authorizeAction(create) → validated(store) → create()
  → with('store') → prepare() → transform() → 201
```

## update

```
find($key) → authorizeAction(update) → validated(update) → applyUpdate()
  → with('update') → prepare() → transform() → 200
```

Registered for both `PUT` and `PATCH`.

## destroy

```
find($key) → authorizeAction(delete) → validated(destroy)
  → delete($model, $data) → 204
```

`destroy` validates like every other action, and the validated data is handed to `delete()`. That lets a `DestroyPostRequest` carry a cascade flag or a reason.

## Adding your own action

A method that is not one of the five is just a controller method:

```php
class DonationGoalController extends CrudController
{
    protected string $model = DonationGoal::class;

    public function redirect(RedirectRequest $request, DonationGoal $goal)
    {
        return redirect(/* … */);
    }
}
```

```php
Route::crud('donation-goals', DonationGoalController::class);
Route::get('donation-goals/{goal}/redirect', [DonationGoalController::class, 'redirect']);
```
