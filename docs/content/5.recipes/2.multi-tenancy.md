---
title: Multi-tenancy
description: Scoping every controller to the current tenant, once.
---

Tenant scoping belongs in `scope()`, and belongs in one place.

```php
abstract class TenantController extends CrudController
{
    protected function scope(Builder $query): Builder
    {
        return $query->where('organization_id', organization()->id);
    }

    protected function create(array $data): Model
    {
        return parent::create($data + ['organization_id' => organization()->id]);
    }
}
```

Every controller extending it is scoped on read and stamped on write.

::caution
`scope()` protects `index`. It does **not** protect `show`, `update` or `destroy`, which resolve by route binding. For those, use a global scope on the model or a policy — a policy is usually the right answer, since it also produces a correct 403.
::

```php
class PostPolicy
{
    public function view(User $user, Post $post): bool
    {
        return $post->organization_id === $user->organization_id;
    }
}
```

## Nested resources

For `posts/{post}/comments`, the parent is a route parameter:

```php
class CommentController extends CrudController
{
    protected string $model = Comment::class;

    protected function scope(Builder $query): Builder
    {
        return $query->where('post_id', request()->route('post'));
    }

    protected function create(array $data): Model
    {
        return parent::create($data + ['post_id' => request()->route('post')]);
    }
}
```

```php
Route::crud('posts/{post}/comments', CommentController::class);
```
